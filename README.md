# Portfólio — Reinaldo Correia

Portfólio pessoal desenvolvido com React, TypeScript e Vite. Reúne uma apresentação profissional, projetos em destaque, trajetória, competências e formas de contato.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Verificação

```bash
npm run build
npm run lint
```

## Interação do retrato

A hero mostra o astronauta sem capacete. Ao passar o ponteiro pelo retrato, uma trilha orgânica revela o capacete. O retrato também pode receber foco pelo teclado e responde ao toque.

O material visual dos projetos é ilustrativo; interfaces e dados de clientes não são publicados neste repositório.
